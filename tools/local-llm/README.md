# Kai 本地模型一键测速（Windows）

`kai-local-test.bat`：双击运行，自动完成下面这些事：

1. 找地方放文件：优先固态硬盘，其次 U 盘或移动硬盘，尽量不用机械硬盘 C 盘。会记住位置，下次不用再选。
2. 下载 llama.cpp b11756 的 Windows Vulkan 版（AMD 显卡也能用），先走国内 GitHub 镜像，下完核对 SHA256。
3. 从魔搭 ModelScope 下载 Qwen 官方的 Qwen3-4B-Q4_K_M.gguf（约 2.5 GB），可选再下 Qwen3-8B-Q4_K_M.gguf（约 5 GB）。下载能断点续传，已经下好的不会重下。
4. 启动本地服务：思考模式关闭，4B 尽量全部放进显卡，然后测速（每秒多少 token / 汉字、回一句话要几秒）。
5. 打开浏览器里自带的聊天网页：http://127.0.0.1:8080

测速结果会存到 `X:\KaiLocal\测速结果.txt`。

停止：在脚本窗口按 Q，或者直接关掉窗口。

局域网接口（OpenAI 兼容，给以后的 iPad app 用）：`http://<这台电脑的局域网 IP>:8080/v1`，模型名 `qwen3-4b`。第一次运行时 Windows 防火墙弹窗要点「允许访问」。

这个脚本里没有任何密钥。
