# 把 @/ 装到 iPad 上：一步步说明

@/ 的 iPad app 已经写好，放在你 GitHub 的 elegant-AI 仓库里，分支叫 **ios-app**。你要做的是：在 iMac 上装一个旧版 Xcode，把代码下载到 iMac，用数据线连上 iPad，点一下运行。第一次大概要半天（大部分时间是在等下载），以后每周重装一次只要两分钟。

下面每一步都需要你亲自在 iMac 或 iPad 上操作，我这边碰不到你的电脑。哪一步卡住了，把屏幕拍给我就行。

## 先记住一件事：iPad 先别更新

设置里提示可以更新到 iPadOS 27.0.1，**先别点**。你的 iMac 只能装旧版 Xcode，我确认过它能往你现在的 iPadOS 26.5 上装 app；升到 27 以后还能不能装，没法保证。为了不被自动更新，可以去「设置 → 通用 → 软件更新 → 自动更新」，把自动安装关掉。

## 第 1 步：在 iMac 上装 Xcode 26.3

你的 iMac 是 macOS 15.7.7，能装的最新版本是 **Xcode 26.3**。苹果官网的表里写着：Xcode 26.3 支持 macOS Sequoia 15.6 到 macOS 26，能往 iOS / iPadOS 15 及以后的设备上装 app。再新一点的 26.4 起就要求 macOS 26.2 了，你的 iMac 装不了。

**不要用 App Store 装**：App Store 里只有最新版，你的 iMac 装不上。

1. 先看看硬盘空间：左上角苹果菜单 → 系统设置 → 通用 → 存储空间。最好空出 **40 GB** 以上（安装包、解压、iPad 组件加起来很大）。
2. 在 iMac 的 Safari 里打开：**developer.apple.com/download/all**
3. 用你的 Apple ID 登录（免费账号就行，第一次可能要你同意一下开发者协议）。
4. 在搜索框里输 **Xcode 26.3**，点开它，下载名字是 Xcode_26.3.xip 的那个文件。文件有好几 GB。
   - 在上海如果页面打不开、登录转圈、或者下载特别慢，开 VPN 再试。下载中断了就重新点一次。
5. 下载好后，在「下载」文件夹里双击 Xcode_26.3.xip，它会自己解压出 Xcode，要等挺久，别关。
6. 把解压出来的 **Xcode** 拖进「应用程序」文件夹。
7. 打开 Xcode。它会问你要装哪些平台，**勾上 iOS**（iPad 用的就是这个），然后点下载。中间要输 iMac 的开机密码就输。这一步也要等一阵。

## 第 2 步：在 Xcode 里登录 Apple ID

1. Xcode 左上角菜单 **Xcode → Settings…**（设置）。
2. 点 **Accounts** 标签，左下角点 **+** → **Apple ID** → 登录你的 Apple ID。
3. 登录后，右边会出现一个叫「你的名字 (Personal Team)」的团队，这就是免费的开发者身份，不用交钱。

## 第 3 步：把代码下载到 iMac

最省事的办法是直接下载压缩包，不用装 git。

1. 在 iMac 的 Safari 里打开这个地址，它会直接下载 ios-app 分支的压缩包：
   **https://github.com/Sarahlittlefish/elegant-AI/archive/refs/heads/ios-app.zip**
   - 也可以打开你的仓库页面，左上角分支切到 ios-app，点绿色的 **Code** → **Download ZIP**。
   - GitHub 打不开就开 VPN。
2. 在「下载」文件夹里双击压缩包解压，会得到一个叫 **elegant-AI-ios-app** 的文件夹。
3. 打开它，进入 **ios** 文件夹，双击 **Kai.xcodeproj**，Xcode 就会打开这个工程。
   - 整个文件夹要保持原样，不要只把 ios 文件夹拿出来：人设和档案文件在外面一层，app 打包时要用。
   - 如果 Xcode 问「是否信任/打开这个工程」，选信任/打开。

## 第 4 步：选你的免费团队（Personal Team）

1. Xcode 左边栏最上面点蓝色的 **Kai**（工程图标）。
2. 中间 TARGETS 下面选 **Kai**，再点上面的 **Signing & Capabilities** 标签。
3. 确认 **Automatically manage signing** 是勾上的。
4. **Team** 那一栏选「你的名字 (Personal Team)」。
5. 如果下面红字说 Bundle Identifier 已经被别人用了，把 **Bundle Identifier** 里的 com.sarahlittlefish.kaichat 改成 com.sarahlittlefish.kaichat2 之类的，红字就会消失。

## 第 5 步：用数据线连上 iPad，打开开发者模式

1. 用数据线把 iPad 插到 iMac 上（iPad Pro 是 USB-C 口，iMac 没有 USB-C 口的话用 USB-C 转 USB-A 的线）。
2. iPad 解锁，弹出「要信任此电脑吗」时点 **信任**，再输 iPad 密码。
3. 在 Xcode 顶部中间，点设备名字那一块，在列表里选你的 **iPad**。第一次连上时，Xcode 可能会显示「正在准备设备」之类的进度，让它跑完，可能要十几分钟。
4. 在 iPad 上打开 **设置 → 隐私与安全性 → 开发者模式**，打开开关。
   - 这个选项要先连过 Xcode 才会出现。找不到的话，先做下面第 6 步点一次运行，再回来找。
5. iPad 会要求**重启**。重启后解锁，弹窗里点 **打开**，再输一次密码。

## 第 6 步：点运行，装到 iPad 上

1. 确认 Xcode 顶部选的是你的 iPad，然后点左上角的 **▶ 三角形**（或按 Command + R）。
2. 第一次编译会慢一点。如果弹出要用钥匙串的窗口，输 iMac 的开机密码，点 **始终允许**。
3. 第一次装好后，app 打不开，Xcode 会报错说开发者不受信任，这是正常的。去 iPad 上信任一下：
   - **设置 → 通用 → VPN 与设备管理**，在「开发者 App」下面点你的 Apple ID，点 **信任**，再确认一次。
4. 回到 Xcode 再点一次 ▶。这次 iPad 上会自己打开 app，桌面上的名字和图标都是「@/」。

## 第 7 步：第一次打开 app

1. **填智谱 API Key**：app 会先让你粘贴智谱的 Key，只要填这一次。
   - Key 在智谱开放平台（open.bigmodel.cn）登录后的 **API Keys** 页面里，就是你之前发给我的那个。在 iPad 上复制，粘贴进去，点保存。
   - Key 只存在这台 iPad 的钥匙串里，不在代码里，也不会上 GitHub。以后每周重装也不用再填。
2. **允许通知**：弹出「想给你发送通知」时点 **允许**，这样他才能偶尔主动找你。
3. 然后你会看到开场那整段聊天记录，最下面是捷克语那句，直接接着聊就行。

App 使用中要联网，可以不开 VPN：它直接连智谱的服务器，智谱在国内，不经过我这边。

## 每 7 天重装一次

免费账号装的 app 只能用 7 天。到期后点图标会提示「无法验证」或「已不再可用」。这时候：

1. 用数据线连上 iMac，打开 Xcode（它一般会自己打开上次的 Kai 工程；没有就再双击一次 ios/Kai.xcodeproj）。
2. 顶部选你的 iPad，点 **▶**。
3. 装完就又能用 7 天。**聊天记录和 Key 都还在**，前提是你没有手动删掉这个 app。所以到期了也别删，直接重装。

## App 里的东西

- **和网页版一样**：顶部只有「@/」，没有 Kai 这个名字。人设、个人档案、开场聊天记录都是原文，一字没改。模型还是 glm-4.6，温度 0.9，关了思考模式。他用空行隔开的几句会变成连发的几个气泡。
- **聊天记录存在 iPad 上**：关掉重开还在，接着上次聊。
- **他知道现在几点了**：每次发消息，app 都会告诉他现在的布拉格时间和北京时间，他就不会乱报时间了。
- **他会偶尔主动找你**：你离开 app 以后，他会在 1 到 3 天后的北京时间晚上 7 点到 10 点之间，发你一个「?」。那时布拉格是下午。没按布拉格傍晚发，是因为那在北京是半夜，会吵你睡觉。你不回，他不会连着发。你打开 app 时，这个「?」会出现在聊天里，你回他，他也看得到自己发过它。不想要可以在设置里关掉。
- **右上角齿轮是设置**：可以换 Key、开关主动消息、导出聊天记录（存成一个文字文件，可以发给我看）、从开场重新开始。
- **额度**：他每回你一条，都会用掉一点你智谱账号的额度，和网页版一样。

## 常见问题

- **Xcode 提示不支持这台 iPad 的系统**：先确认 iPad 没有升到 27，再把 iPad 拔了重插、重开 Xcode。还不行就拍给我。
- **红字 Signing 报错**：多半是 Team 没选，或者 Bundle Identifier 重名，看第 4 步。
- **找不到开发者模式**：先连着 Xcode 点一次 ▶，它就会出现。
- **消息发不出去**：聊天里会出现一行灰色斜体的「消息没发出去」和原因。多半是网络或 Key 的问题，把那行字拍给我就行。这行提示不会发给他。
